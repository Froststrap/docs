# File Outputs

Where our Fallout build system spits everything out, and the meaning

## What is `.build/publish`

This directory is for `dotnet publish` wrapper to put all the stuff into.

## What is `.build/build`

This one is same relation as `.build/publish`, but instead for dumps of
`dotnet msbuild`

## What is `.build/dist`

This one is common and would be self-explanatory, but also has junk to do with
making the dist stuff too, so on macOS is has the unsigned .app, and also on Linux
it as a app manifest directory in it, for tools to build the .rpm, .deb, and .AppImage
