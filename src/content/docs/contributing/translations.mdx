# Translations

If you use Froststrap in a language that isn't supported yet, or the existing translation is missing strings or has mistakes, you can help fix it.

All translations are managed on our Crowdin project, so there's no need to edit any files or open a pull request.

## How to contribute

1. Go to the [Froststrap Crowdin project](https://crowdin.com/project/froststrap).
2. Sign in or create a free Crowdin account.
3. Pick your language. If it isn't listed, request it from the project page.
4. Translate or review strings directly in the browser.

Approved translations are included in a later Froststrap release.

## Language not listed?

Request it on Crowdin, or let us know through our usual support channels and we'll add it.
